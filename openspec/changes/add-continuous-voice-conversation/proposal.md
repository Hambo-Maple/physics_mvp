# Change: 添加连续语音对话模式

## Why
当前语音输入功能需要用户手动点击按钮开始/停止录音，每次对话都需要重复操作，交互效率低。用户希望实现类似智能音箱的连续对话体验：说话 → 自动识别 → AI回答 → 继续监听，全程无需手动干预，提升物理学习场景下的交互流畅度。

## What Changes
- 在对话输入区新增【连续语音对话】按钮，位于现有语音输入按钮旁边
- 实现连续语音对话模式：持续监听麦克风 → 静音检测（1.5秒阈值）→ 自动停止录音 → 自动识别 → 自动发送 → AI流式回答 → 自动更新可视化参数 → 继续监听下一段
- 连续模式下的视觉反馈：
  - 顶部状态栏显示"正在连续语音对话中..."
  - 连续语音按钮变色并闪烁
  - 显示简单条形波动的麦克风波形动画（3-5个竖条随音量波动）
- 冲突处理策略：等待AI回答完成后再开始下一轮监听，避免打断AI输出
- 保持所有现有功能不变：流式输出、公式渲染、鼠标吸附、轨迹显示、对话上下文、平抛参数调节、单次语音识别

## Impact
- 新增能力：continuous-voice-mode（连续语音对话模式）
- 影响文件：
  - `src/components/ChatBox.vue` - 新增连续语音按钮、状态管理、自动循环逻辑
  - `src/utils/voice.js` - 新增静音检测、音量分析功能
  - `src/store/index.js` - 新增连续语音模式状态
  - `src/assets/ChatBox.css` - 新增按钮样式、波形动画、状态栏样式
- 用户体验提升：从"点击-说话-点击-发送"4步操作简化为"点击开启-持续对话"
- 无破坏性变更，现有单次语音输入功能保持独立可用

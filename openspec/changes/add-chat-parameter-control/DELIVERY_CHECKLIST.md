## ✨ 核心功能

### 支持的指令类型（8 种）

| 指令类型 | 示例 | 功能 |
|---------|------|------|
| 绝对值调整 | `初速度 20` | 设置参数为指定值 |
| 相对调整 | `初速度增加 5` | 在当前值基础上增减 |
| 范围查询 | `初速度的范围是多少` | 查询参数取值范围 |
| 重置参数 | `重置平抛参数` | 恢复所有参数为默认值 |
| 播放动画 | `播放平抛动画` | 开始播放动画 |
| 暂停动画 | `暂停平抛动画` | 暂停动画播放 |
| 调整倍速 | `调速 2 倍` | 设置动画播放速度 |
| 单步前进 | `单步前进` | 动画前进一帧 |

### 支持的参数（5 个）

| 参数 | 别名 | 范围 | 单位 | 默认值 |
|------|------|------|------|--------|
| 初速度 | v0/速度 | 1-50 | m/s | 10 |
| 重力加速度 | g/重力 | 1-20 | m/s² | 9.8 |
| 初始高度 | h/高度 | 10-200 | m | 50 |
| 发射角度 | θ/theta/角度 | 0-90 | ° | 0 |
| 质量 | m/mass | 0.1-10 | kg | 1 |

### 关键特性

✅ **混合模式识别**
- 精准匹配：`参数名 + 数值 + 单位`
- 自然语言：`把初速度调到 20`
- 参数别名：支持中英文多种表达

✅ **智能校验修正**
- 参数范围自动校验
- 超出范围自动修正到边界值
- 友好的错误提示信息

✅ **实时同步更新**
- 对话指令 → 全局状态 → 画布更新
- 公式展示区实时更新
- 鼠标吸附功能读取最新参数

✅ **完全兼容**
- 不破坏原有流式输出功能
- 不破坏原有语音输入功能
- 不破坏原有鼠标吸附功能
- 不破坏原有公式渲染功能
- 保持墨绿色主题一致

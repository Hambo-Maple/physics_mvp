## 技术亮点

### 1. 混合模式解析引擎

```javascript
// 优先级：重置 > 动画控制 > 范围查询 > 相对调整 > 绝对值调整
export function parseProjectileParams(message) {
  if (/重置|恢复默认/.test(message)) return { type: 'reset' };
  if (/播放|开始/.test(message)) return { type: 'play' };
  // ... 依次检测其他类型
}
```

### 2. 智能参数校验

```javascript
export function validateProjectileParams(params) {
  const validated = {};
  const corrections = [];

  for (const [key, value] of Object.entries(params)) {
    if (value < range.min) {
      validated[key] = range.min;
      corrections.push({ param: key, reason: 'below_min' });
    } else if (value > range.max) {
      validated[key] = range.max;
      corrections.push({ param: key, reason: 'above_max' });
    }
  }

  return { params: validated, corrections };
}
```

### 3. 组件通信方案

```
App.vue
  └─ visualCanvasRef (ref)
      └─ VisualCanvas.vue
          └─ projectileMotionRef (ref)
              └─ ProjectileMotion.vue
                  └─ defineExpose({ togglePlayPause, ... })

ChatBox.vue
  └─ props.visualCanvasRef?.projectileMotionRef?.togglePlayPause()
```

**优势：** 直接调用、类型安全、调试方便

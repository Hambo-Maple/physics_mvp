# Proposal: 对话消息控制平抛运动参数

## Change ID
`add-chat-parameter-control`

## Summary
实现通过左侧对话消息调整右侧平抛运动可视化参数的功能，支持混合模式指令识别（精准匹配 + 自然语言解析），包括单/多参数调整、重置、动画控制等指令类型。

## Motivation
当前用户只能通过右侧画布的参数控制面板手动调整平抛运动参数，缺乏自然语言交互能力。增加对话指令控制功能后，用户可以通过自然语言快速调整参数（如"初速度 20m/s"、"重力改成 10，高度 50"），提升交互体验和学习效率。

## Goals
1. 实现混合模式指令识别：精准匹配（参数名+数值+单位）+ 自然语言解析（口语化指令）
2. 支持单参数、多参数批量调整、重置参数、动画控制等指令类型
3. 支持参数的相对调整（如"初速度增加 5"、"重力减少 2"）
4. 支持参数范围查询（如"初速度的范围是多少"）
5. 参数异常处理：解析失败提示、数值超出范围自动修正
6. 对话指令与画布状态实时同步，保持所有现有功能不受影响

## Non-Goals
- 不实现语音指令控制（语音输入已有，但不针对参数控制做特殊优化）
- 不实现参数调整历史记录/撤销功能
- 不实现参数预设方案保存/加载功能

## Affected Capabilities
- `chat-parameter-control` (NEW) - 对话指令解析与参数控制核心能力

## Dependencies
- 依赖现有的 `src/store/index.js` 全局状态管理
- 依赖现有的 `src/components/ProjectileMotion.vue` 平抛运动可视化组件
- 依赖现有的 `src/components/ChatBox.vue` 对话组件

## Risks & Mitigations
| Risk | Mitigation |
|------|------------|
| 指令解析误识别导致参数错误调整 | 精准匹配优先，自然语言解析作为备选；解析失败时不调整参数并提示用户 |
| 参数调整与画布状态不同步 | 统一通过 `updateProjectileParams` 更新全局状态，触发响应式更新 |
| 破坏现有功能（流式输出、语音输入等） | 指令解析逻辑独立封装，仅在识别到有效参数时触发，不影响原有对话流程 |

## Success Criteria
- [ ] 用户发送"初速度 20m/s"，AI 回复确认并画布参数更新为 v0=20
- [ ] 用户发送"重力改成 10，高度 50"，AI 回复确认并画布参数批量更新
- [ ] 用户发送"初速度增加 5"，AI 回复确认并画布参数从当前值增加 5
- [ ] 用户发送"重力减少 2"，AI 回复确认并画布参数从当前值减少 2
- [ ] 用户发送"初速度的范围是多少"，AI 回复包含 "1 ~ 50 m/s"，画布参数不变
- [ ] 用户发送"所有参数的范围"，AI 回复包含所有参数范围列表，画布参数不变
- [ ] 用户发送"重置平抛参数"，AI 回复确认并所有参数恢复默认值
- [ ] 用户发送"播放平抛动画"，AI 回复确认并画布动画开始播放
- [ ] 用户发送超出范围的参数（如"初速度 100"），AI 回复提示已修正为边界值（50）
- [ ] 用户发送无效指令（如"显示公式"），AI 正常回复，不调整参数
- [ ] 所有现有功能（流式输出、语音输入、鼠标吸附、公式渲染）保持正常工作
